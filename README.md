## 更新前の注意
既存アプリの設定から学習データをJSONバックアップしてください。保存キー `basicInfoQuestSave_v1` は維持していますが、元の初期版と保存形式が異なる場合は移行確認が必要です。

## 更新方法
GitHubリポジトリの `Add file > Upload files` から、index.html / style.css / app.js / manifest.webmanifest / sw.js / icon.svg をアップロードし、同名ファイルを置き換えてCommitします。公開反映後、Safariでサイトを開き直してください。

この版は科目A基礎問題を50問収録した拡張版です。試験全範囲を網羅した公式問題集ではありません。AI APIはサーバー側エンドポイントが必要です。
